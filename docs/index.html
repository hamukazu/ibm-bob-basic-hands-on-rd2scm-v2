よくある質問

IBM Bob に関するよくある質問をまとめています。質問をクリックすると回答が表示されます。

一般

Bob は、コードの作成・リファクタリング・各種タスクの実行を支援するAI搭載のコーディングコンパニオンです。カスタムモードやカスタムインストラクションにより、機能を拡張することができます。

Bob は大規模言語モデル（LLM）を使用してリクエストを理解し、アクションに変換します。主な機能は以下のとおりです。

  • プロジェクト内のファイルの読み書き
  • ターミナルでのコマンド実行
  • インターネットの閲覧（有効化時）
  • Model Context Protocol（MCP）を通じた外部ツールの利用

チャットインターフェースを通じて指示を入力し、Bob が提案したアクションを確認・承認しながら操作します。

Bob はさまざまなコーディングタスクをサポートします。

  • 自然言語の説明からコードを生成する
  • 既存コードをリファクタリングする
  • バグを修正する
  • ドキュメントを作成する
  • コードを説明する
  • コードベースに関する質問に答える
  • 繰り返し作業を自動化する
  • 新しいファイルやプロジェクトを作成する

以下のデータ種別は Bob で処理しないでください。

  • SPI（特定個人情報）
  • PHI（個人医療情報）
  • 輸出規制対象データ（ITAR、APPなど）
  • 規制対象の金融データ（銀行口座番号、PAN、非公開の財務データなど）

Bob は強力なツールです。責任を持って使用してください。

  • Bob は間違えることがあります。承認前に、Bob が提案した変更を必ず丁寧に確認してください。
  • Bob はコマンドを実行できます。自動承認を使用している場合は特に、コマンド実行の際は慎重に対応してください。

使い方

Bob パネルを開き、チャットボックスにタスクを入力してください。Bob に何をしてほしいかを、明確かつ具体的に記述してください。

チャット入力エリアのドロップダウンメニューから別のモードを選択するか、/ コマンドを使用して特定のモードに切り替えてください。

ツールは Bob がシステムと対話するための手段です。Bob はタスクを完了するために適切なツールを自動的に選択して使用します。ツールを直接呼び出す必要はありません。各ツールの使用時には、承認または拒否を求めるプロンプトが表示されます。

コンテキストメンションは、ファイル・フォルダー・問題点など、プロジェクトに関する特定の情報を Bob に伝える方法です。@ 記号の後に対象アイテムを入力して使用します（例: @/src/file.ts、@problems）。

はい、Bob はコマンドを実行できます。コマンドの自動承認を有効にしていない限り、各コマンドの実行前に承認を求めるプロンプトが表示されます。コマンドの自動承認を有効にする際は十分にご注意ください。

Bob が提案したアクションを承認または拒否することでフィードバックできます。フィードバック欄を使用して追加のコメントを入力することもできます。

はい、いくつかの方法でカスタマイズできます。

  • カスタムインストラクション: 全モード共通の指示、またはモード別の指示を設定できます。
  • カスタムモード: 独自のプロンプトとツール権限を持つモードを作成できます。
  • Bob ルール: プロジェクトルートの .bob/rules/ フォルダーにMarkdownルールファイルを作成して追加ガイドラインを設定できます。
  • 設定: 自動承認・差分編集など、各種設定を調整できます。

はい、有効にするとアクションを自動的に承認するいくつかの設定があります。

高度な機能

MCP は Bob が外部サーバーと通信するためのプロトコルで、カスタムツールやリソースを追加することで Bob の機能を拡張できます。

はい、独自のMCPサーバーを作成して Bob にカスタム機能を追加することができます。

トラブルシューティング

  • APIキーが正しいこと、有効期限が切れていないことを確認してください。
  • インターネット接続を確認してください。
  • VS Code を再起動してみてください。

Bob は VS Code の標準的なファイル編集機能を使用しています。標準の「元に戻す」コマンド（Ctrl / Cmd + Z）で変更を取り消すことができます。また、チェックポイントを使用してファイルへの変更を特定時点まで戻すこともできます。
