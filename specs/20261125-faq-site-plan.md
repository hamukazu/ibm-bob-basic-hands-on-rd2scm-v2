## 実装手順

1. ヘッダー左上に `<a href="https://www.ibm.com/products/bob" target="_blank"><img src="../bob.svg" ...></a>` を追加する
2. ヘッダー右上にライト/ダーク切り替えトグルボタンを追加する
3. CSS を更新する
   - テーマカラーを `#3b82d4` から `#0f62fe` に変更する
   - CSS カスタムプロパティ（変数）でライト/ダーク両テーマの色を定義する
   - `body.dark` セレクターでダークテーマを適用する
4. JS を更新する
   - トグルボタンクリックで `body.dark` クラスをトグルする
   - 設定を `localStorage` に保存・復元する
5. ブラウザで表示・動作を確認する

## GUI実装

* **対象コンポーネント:** 1ファイル完結（`docs/index.html`）
* **スタイル:** インラインCSS（外部ファイル・CDN不使用）
  * フォント: `-apple-system, "Hiragino Sans", "Meiryo", sans-serif`
  * ページ最大幅: 760px（中央寄せ）
  * テーマカラー: `#0f62fe`（IBM Blue）— カテゴリ見出し・フォーカスリング・アクセントに使用
  * カテゴリ見出し: `<h2>` スタイルで区切り
  * アコーディオン質問: クリック可能な `<button>` 要素
  * アコーディオン回答: `<div>` を表示/非表示で切り替え
  * ダークテーマ: `body.dark` クラスによる色の上書き（背景 `#161616`、文字 `#f4f4f4`）
* **ヘッダー:**
  * 左: `<a>` でラップした Bob ロゴ画像（`../bob.svg`、高さ 40px）
  * 右: テーマ切り替えボタン（🌙/☀️ のアイコン表示）
* **状態管理:**
  * アコーディオン: `aria-expanded` 属性とCSSクラスでトグル（Vanilla JS）
  * テーマ: `body.dark` クラスのトグル＋`localStorage` による永続化
* **画面遷移:** なし（1ページ完結）
* **レスポンシブ対応:** `max-width` による基本的な横幅制御のみ
